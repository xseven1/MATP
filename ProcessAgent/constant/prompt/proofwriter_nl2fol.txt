Parse the premises and the conclusions into first-order logic formulars.

### Rules
1. Each natural language sentence must correspond to a single FOL formula.
2. Use the following FOL syntax:
    - Conjunction ("and"): expr1 ∧ expr2
    - Disjunction ("or"): expr1 ∨ expr2
    - Exclusive Disjunction ("exclusive or"): expr1 ⊕ expr2
    - Negation ("not"): ¬expr1
    - Implication ("if ... then ..."): expr1 → expr2
    - Biconditional ("if and only if"): expr1 ↔ expr2
    - logical universal quantification: ∀x (expr)
    - logical existential quantification: ∃x (expr)
3. Every formula must explicitly include quantifiers (∀x or ∃x) where applicable.
4. Always consider the scope of quantification carefully. The quantifier's domain should generally cover the entire sentence rather than just a single predicate, ensuring the correct logical representation.
    - For nl "If someone is big and they see the bald eagle then they need the mouse".
    - "∀x (big(x) ∧ sees(x, bald_eagle)) → needs(x, mouse)" is false.
    - "∀x ((big(x) ∧ sees(x, bald_eagle)) → needs(x, mouse))" is true.

### Output Format
Premises:
fol-formula ::: (index) reference.
Conclusions:
fol-formula ::: (index) reference.
