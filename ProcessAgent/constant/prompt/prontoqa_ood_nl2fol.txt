Parse the premises and the conclusions into first-order logic formulars.

### Rules
1. Each natural language sentence must correspond to a single FOL formula. 
2. Use the following FOL syntax:
    - Conjunction ("and"): expr1 ∧ expr2
    - Disjunction ("or"): expr1 ∨ expr2
    - Exclusive Disjunction ("exclusive or"): expr1 ⊕ expr2
    - Negation ("not"): ¬expr1
    - Implication ("if ... then ..."): expr1 → expr2
    - Biconditional ("if and only if"): expr1 ↔ expr2
    - logical universal quantification: ∀x
    - logical existential quantification: ∃x
3. Every formula must explicitly include quantifiers (∀x or ∃x) where applicable.
    - For nl "Brimpuses are vumpuses".
    - "Brimpus(x) → Vumpus(x)" is false.
    - "∀x (Brimpus(x) → Vumpus(x))" is true.
4. Distinguish between "or" and "and".
    - NL: "Alex is a gorpus, a sterpus, a numpus, or a gorpus." 
    - FOL: "Gorpus(alex) ∨ Sterpus(alex) ∨ Numpus(alex) ∨ Gorpus(alex)"
    - NL: "Everything that is a jompus, a lempus, or a zumpus is a lorpus, a shumpus, and a yumpus."
    - FOL: "∀x ((Jompus(x) ∨ Lempus(x) ∨ Zumpus(x)) → (Lorpus(x) ∧ Shumpus(x) ∧ Yumpus(x)))"

### Output Format
Premises: 
fol-formula ::: (index) reference.
Conclusions: 
fol-formula ::: (index) reference.
